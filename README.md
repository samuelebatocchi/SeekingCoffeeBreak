# Seeking Coffee Break 🏃💨

A fast-paced wall running mobile game built with Unity.

## ✨ Features

- Fluid wall-running mechanics
- In-game shop with unlockable skins (more coming soon!)
- Coffee cup currency system
- Cloud save via Google or Unity login — never lose your best score, skins, or coffee cups

## 📥 Download

Prebuilt releases (Android APK / iOS Xcode project) are available on the [Releases page](../../releases).

| Platform | Minimum version |
|----------|-----------------|
| Android  | 7.1+ |
| iOS      | 15.0+ |

## ⚠️ iOS Build Status

We don't currently have access to a Mac (and therefore Xcode), so we haven't been able to produce and test a final iOS build. The game runs correctly in the Unity Editor/simulator, so the iOS Xcode project provided in the [Releases](../../releases) should work in principle, but it hasn't been verified on a real device. If you have a Mac and can help test or build it, feel free to open an issue or reach out!

## 🛠️ Built with

- Unity `6.3`
- C#
- Unity Authentication (Google / Unity login)
- Unity Cloud Save (cloud data persistence for scores, skins and currency)

## 🚀 Getting started (development)

1. Clone this repository
2. Open the project with **Unity Hub** using Unity version `6.3`
3. Open the main scene from `Assets/Scenes/"Main Menu"`
4. Press Play in the Editor to test, or use **File → Build Settings** to build for Android/iOS

## 📂 Project structure

- `Assets/` — game assets, scripts, scenes, prefabs
- `ProjectSettings/` — Unity project configuration
- `Packages/` — package dependencies
